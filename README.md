# Backend Basics

Учебный проект для знакомства со структурой Python-проекта. В нём показаны
dataclass-модель, хранение задач в словаре, собственное исключение и логирование.

## Требования

- Python 3.12
- зависимости из `requirements.txt`

## Установка

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Проверка кода

```bash
ruff check .
ruff format .
```
